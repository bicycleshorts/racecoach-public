# RaceCoach

RaceCoach turns onboard video and GPS telemetry into clear, practical performance analysis for drivers.

This repository is the public home for RaceCoach information and resources. Public material is published here from the private RaceCoach development repository through an explicit, allowlisted export process.

## Release notes

See the [RaceCoach changelog](CHANGELOG.md) for the latest improvements, fixes, and previous releases.

## What may be published here

Over time, this repository may include:

- Release notes and product announcements
- Public documentation and support material
- Examples intended for general use
- Links to RaceCoach downloads and services

The RaceCoach application source code and private development material are not published here.

## Availability

RaceCoach is under active development. Product availability and download links will be added when they are ready for public release.
